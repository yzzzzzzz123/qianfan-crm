# 千帆 CRM 浏览器独立试用版

静态公开试用与单文件HTML使用相同构建，支持管理员/销售演示身份、客户、商机、跟进、报价、合同、回款等现有业务操作。代码复用主系统业务服务和校验，以sql.js提供浏览器SQLite。

- 每位测试者的数据保存在自己的浏览器localStorage；不同浏览器、设备、网址与文件各自独立，不共享业务记录。
- 演示身份切换用于体验，所有代码和演示资料均公开，不能作为真实账号权限隔离或生产业务系统。
- 初始客户及成员使用虚构演示名称；不发布运行数据库、密码或真实业务资料。
- 隐私窗口、禁用浏览器存储或清理网站数据可能导致试用记录丢失。页面支持导出测试数据与恢复演示数据。
- 未连接钉钉、通知、AI表格或正式模板。多人共享数据与真实身份需使用主系统服务端部署。

## 构建

Node.js 24，执行 `npm ci`、`npm run build`。在主项目子目录内构建时，刷新主系统源码副本；独立下载本仓库后则使用保留的浏览器适配源码。输出为 `dist/index.html`，可静态托管或复制为单个HTML文件。

验证：`node --test test-trial.mjs`。测试独立的内存存储，不更改访问者的试用记录。7条涵盖密码算法一致性、初始化/身份、客户商机跟进、合同回款/幂等/超额、重启保留、销售业务限制、存储失败回滚。浏览器实际另测打开、登录、创建客户和刷新保留。

页面支持Windows上的当前版本Edge/Chrome，可双击HTML打开，无需Node.js、千问办公或本地服务器。浏览器文件访问与存储策略可能不同；网络版可直接用HTTPS地址。
